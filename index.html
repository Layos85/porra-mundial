🔌 Conectar con Supabase

Esta web necesita una base de datos gratuita de Supabase para que todos los amigos jueguen sincronizados. Solo hay que hacerlo una vez.

  1. Crea una cuenta y un proyecto gratis en supabase.com.
  2. En SQL Editor pega el contenido de supabase-schema.sql y pulsa Run.
  3. En Project Settings → API copia la Project URL y la clave anon public.
  4. Pégalas aquí abajo (o, mejor, en el archivo config.js para que sea permanente).
